# UstaCebim

Hizmet arayanlarla hizmet verenleri buluşturan platformun bağımsız geliştirme deposu.

## İlk aşama
- Hizmet talebi ve teklif akışı
- Usta profilleri
- Aylık/yıllık abonelik ve ek teklif hakları (şimdilik demo)
- İş/eleman ilanları kapsam dışı

## Çalıştırma
`index.html` dosyasını tarayıcıda açın. Veriler test amaçlı yalnızca tarayıcıda tutulur.

## Güvenlik
Bu sürümde gerçek ödeme, banka havalesi doğrulaması, kullanıcı doğrulaması veya fatura düzenleme yoktur. Canlı müşteri verisi girilmemelidir. İleriki aşamada sunucu, veritabanı ve yetkilendirme eklenecektir.

Çizmece oyununun kodundan ve veritabanından bağımsızdır.
